# mossy-launcher

This repository contains the Mossy Launcher cloud apps and the new desktop scaffold.

## 🚀 Quick Start

**Want to use Mossy Launcher?**
- See [INSTALL.md](INSTALL.md) for download and installation instructions
- **Do NOT download the "Code" ZIP** - it won't work! Download from [Releases](https://github.com/POINTYTHRUNDRA654/mossy-launcher/releases) instead

## 📁 Repository Structure

**Desktop scaffold (Windows):**
- `desktop/electron-windows/` - Electron-based prototype desktop application that connects to the cloud backend and provides initial hooks for voice I/O, program observation, TTS, local ML/RL logging, and secure token storage.

See `desktop/electron-windows/README.md` for development instructions.
